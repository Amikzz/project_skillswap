# SkillSwap

SkillSwap is a mobile application that connects people who want to learn new skills with those who are willing to share their expertise. The app is built with Flutter and Dart.

## Purpose

The main purpose of SkillSwap is to create a community where people can easily exchange skills and knowledge. Whether you want to learn a new language, a musical instrument, a programming language, or any other skill, SkillSwap helps you find the right person to learn from.

## Features

-   **User Registration and Login:** Users can create an account and log in to the app.
-   **Skill Listing:** Users can list the skills they are willing to teach and the skills they want to learn.
-   **Search and Filter:** Users can search for skills and filter them by category.
-   **Provider Listing:** Users can see a list of all skill providers.
-   **User Profiles:** Users have a profile page where they can see their information.
-   **Notifications:** Users receive notifications for skill requests, offers, and other activities.
-   **Orders:** Users can track their ongoing and completed skill-sharing sessions.

## Setup

To set up the project on your local machine, follow these steps:

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/your-username/skillswap.git
    ```

2.  **Install dependencies:**

    ```bash
    flutter pub get
    ```

3.  **Run the app:**

    ```bash
    flutter run
    ```

## Usage

Once the app is running, you can:

1.  **Register a new account:** If you are a new user, you can create a new account by providing your name, email, and password.
2.  **Log in:** If you already have an account, you can log in using your email and password.
3.  **Explore skills:** You can browse the list of available skills and filter them by category.
4.  **Find a provider:** You can see a list of all skill providers and view their profiles.
5.  **Share your skills:** You can list the skills you are willing to teach and become a skill sharer.
